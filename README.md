# Survei SMAKNIS

Aplikasi survei berbasis web. Laravel 12, Tailwind CSS 4, Vite.

## Technology Stack

- Laravel 12 (`laravel/framework ^12.0`)
- PHP ^8.3
- Node.js 22.x, npm
- Vite 7, `laravel-vite-plugin`
- Tailwind CSS 4
- MySQL, SQLite sebagai alternatif
- Session, Cache, Queue: driver `database`

## Requirements

- PHP 8.3+
- Composer 2.x
- Node.js 22.x, npm
- MySQL/MariaDB atau SQLite
- Git

## Installation

```powershell
git clone <repository-url> survei-smaknis
cd survei-smaknis

composer install
copy .env.example .env
php artisan key:generate
php artisan migrate
php artisan storage:link

npm install
```

## Configuration

| Key | Example Value |
|-----|---------------|
| `APP_NAME` | `Survei-SMAKNIS` |
| `APP_URL` | `http://localhost` |
| `APP_KEY` | Generated by `key:generate` |
| `DB_CONNECTION` | `mysql` |
| `DB_HOST` | `127.0.0.1` |
| `DB_PORT` | `3306` |
| `DB_DATABASE` | `survei-smaknis` |
| `DB_USERNAME` | `root` |
| `DB_PASSWORD` | `` |

## Usage

Development:

```powershell
php artisan serve
npm run dev
```

Production:

```powershell
npm run build
php artisan serve
```

`http://127.0.0.1:8000`
